# Khaled Test — EMW Clinical Workspace

A lightweight, front-end-only EMR interface prototype inspired by the information density and workflow style of large enterprise EHRs such as Epic, without copying proprietary Epic assets or code.

## Demo
- Patient banner and chart context
- Visit summary, vitals, safety, assessments, medications, care gaps
- Interactive chart tabs and navigation
- Editable sticky note
- Responsive desktop/tablet layout

This repository is a UI prototype only. It contains synthetic patient data and is not intended for clinical use.
